# Stream Vessel AI integrations

Public AI integrations for Stream Vessel: MCP configurations, plugins, skills, and examples for working with files and data across connected services.

The [Stream Vessel plugin](plugins/streamvessel/README.md) connects ChatGPT and Codex to your connected services through the hosted MCP server at https://mcp.streamvessel.com.

## Integrations

- [Stream Vessel plugin for ChatGPT and Codex](plugins/streamvessel/README.md): setup, testing, and packaging instructions.
- [Plugin manifest](plugins/streamvessel/plugin.json): plugin identity and listing metadata.
- [MCP configuration](plugins/streamvessel/mcp.json): Streamable HTTP connection with OAuth authentication.
- [Catalog listings](CATALOGS.md): every public MCP catalog that lists the server, and how each listing is maintained.
- [MCP Registry entry](server.json): the server's entry in the official MCP Registry.
- [Stream Vessel skill](plugins/streamvessel/skills/streamvessel/SKILL.md): workflows for exploring connections, finding and inspecting files, and organizing files and data.
